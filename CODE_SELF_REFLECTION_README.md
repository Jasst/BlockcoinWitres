# Улучшения AI-системы (Code Self-Reflection)

## Обзор

Добавлена система самоанализа кода, позволяющая ИИ читать свой код, искать по нему, анализировать ошибки и предлагать исправления. Это первый шаг к созданию truly самообучающейся системы.

## Что добавлено

### 1. Конфигурация (`GCN/config_ai.py`)

```python
# Самоанализ кода (Code Self-Reflection)
ENABLE_CODE_SELF_REFLECTION = True          # Включить/выключить функцию
CODE_ANALYSIS_MAX_FILES = 10                # Лимит файлов за один анализ
CODE_CONTEXT_MAX_LINES = 50                 # Макс. строк контекста вокруг ошибки
AUTO_FIX_SUGGESTIONS = True                 # Предлагать исправления автоматически
CODE_ACCESS_ROOT = Path(...)                # Корень для доступа к коду
ALLOWED_CODE_EXTENSIONS = {".py", ".json", ...}  # Безопасные расширения
```

### 2. Анализатор кода (`GCN/code_analyzer.py`)

Новый модуль с 4 основными функциями:

#### `read_file(path, max_lines)`
- Читает файлы проекта с проверкой безопасности
- Кэширует прочитанные файлы
- Ограничивает доступ только разрешёнными расширениями
- Пример использования ИИ: `"Прочитай файл GCN/tool_router.py"`

#### `search_in_code(pattern, max_results)`
- Ищет текст или regex-паттерны в коде
- Возвращает контекст вокруг найденных совпадений
- Пропускает __pycache__ и скрытые директории
- Пример: `"Найди все упоминания TOOL_CALL_TIMEOUT"`

#### `get_project_structure(max_depth)`
- Возвращает дерево структуры проекта
- Фильтрует по безопасным расширениям
- Пример: `"Покажи структуру проекта"`

#### `analyze_error_location(error_message, traceback)`
- Анализирует traceback и находит проблемные строки
- Предлагает эвристические исправления для типичных ошибок:
  - IndexError → проверка границ массива
  - KeyError → использование .get() или проверки in
  - AttributeError → проверка типа объекта
  - TypeError → проверка сигнатур функций
  - NameError → проверка импортов
  - ImportError → проверка зависимостей

### 3. Инструменты для ИИ (`routes/ai_assistant.py`)

Зарегистрированы 4 новых внутренних инструмента:

| Инструмент | Описание |
|------------|----------|
| `internal__read_code` | Читает файл кода |
| `internal__search_code` | Ищет паттерн в коде |
| `internal__project_structure` | Показывает структуру проекта |
| `internal__analyze_error` | Анализирует ошибку |

### 4. Обновлённый ToolRouter (`GCN/tool_router.py`)

- Добавлены примеры использования в few-shot промпт
- Новые правила для распознавания намерений анализа кода
- Примеры в каталоге инструментов

## Как это работает

### Сценарий 1: Пользователь сообщает об ошибке

```
Пользователь: "У меня ошибка KeyError: 'user_id' в routes/ai_assistant.py"

ИИ (автоматически):
1. Вызывает internal__analyze_error с error и traceback
2. Получает анализ с указанием на строку 123
3. Вызывает internal__read_code для чтения файла с контекстом
4. Анализирует код и предлагает исправление
5. Объясняет пользователю решение
```

### Сценарий 2: Поиск по коду

```
Пользователь: "Где у нас определяется таймаут для MCP инструментов?"

ИИ:
1. Вызывает internal__search_code с pattern="TOOL_CALL_TIMEOUT"
2. Находит 3 совпадения в mcp_client_manager.py
3. Читает файл и объясняет логику
```

### Сценарий 3: Анализ структуры

```
Пользователь: "Как организован проект?"

ИИ:
1. Вызывает internal__project_structure с max_depth=2
2. Получает дерево файлов и директорий
3. Объясняет архитектуру по уровням
```

## Безопасность

Система включает многоуровневую защиту:

1. **Проверка путей**: Файлы должны находиться внутри CODE_ACCESS_ROOT
2. **Фильтр расширений**: Только .py, .json, .md, .txt, .yml, .yaml
3. **Запрет относительных путей**: Нельзя выйти за пределы корня через ../
4. **Лимиты**: Ограничение на количество файлов и строк
5. **Кэширование**: Снижает нагрузку на файловую систему

## Производительность

- **Кэш файлов**: Прочитанные файлы кэшируются в памяти
- **Ленивая загрузка**: Анализатор создаётся только при первом использовании
- **Оптимизированный поиск**: Пропуск бинарных файлов и кэша
- **Асинхронность**: Все операции async/await не блокируют основной цикл

## Интеграция с MCP

Инструменты самоанализа доступны как через браузерный чат, так и через MCP-клиенты (Claude Desktop и др.):

```json
{
  "name": "read_code",
  "description": "Читает файл исходного кода проекта...",
  "parameters": {...}
}
```

## Отключение

Для отключения функции установите в `config_ai.py`:

```python
ENABLE_CODE_SELF_REFLECTION = False
```

Все инструменты будут скрыты из каталога.

## Тестирование

Запустите тестовый скрипт:

```bash
python -c "
import asyncio
from GCN.code_analyzer import get_analyzer

async def test():
    a = get_analyzer()
    print(await a.read_file('GCN/config_ai.py', max_lines=10))
    print(await a.search_in_code('TOOL_CALL_TIMEOUT', max_results=2))
    print(await a.get_project_structure(max_depth=2))

asyncio.run(test())
"
```
